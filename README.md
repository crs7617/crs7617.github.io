# Sairam CR Portfolio

Static personal portfolio for GitHub Pages.

## Files

- `index.html` - semantic single-page content with about, projects, tech, and stats sections
- `styles.css` - theme variables, layout, and responsive styling
- `script.js` - theme toggle persistence and GitHub stats loading/caching
- `assets/` - favicon and social preview placeholder

## Notes

- No build step, no framework, no dependencies.
- Push to `main` to deploy on GitHub Pages.
- Replace the NOIV repo link and personal social placeholders in `index.html` when ready.
